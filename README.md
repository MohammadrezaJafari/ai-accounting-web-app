# AI Accounting — پنل مشتری

پنل مشتری پروژهٔ [ai-accounting](https://github.com/MohammadrezaJafari/ai-accounting)، با Quasar (Vue 3 + TypeScript) و راست‌به‌چپ. ساختار آن همان الگوی `insurance-web-app` است.

ظاهر پنل تیره و به سبک پلتفرم‌های توسعه‌دهندگان (مثل GapGPT و OpenRouter) است. در این پنل مشتری می‌تواند:

- در **داشبورد** آدرس پایهٔ API، نمونه‌کد شروع سریع، مدل‌های ویژه و دسترسی سریع به راهنماها را ببیند.
- **اپ** بسازد. هر اپ کیف پول (موجودی دلاری) جدا دارد.
- **کلید API** بسازد (برای یک اپ یا از صفحهٔ «کلیدهای API» برای همهٔ اپ‌ها)، کلید را به ارائه‌دهنده‌ها یا مدل‌های خاص محدود کند و سقف هزینه و انقضا بگذارد.
- در **کیف پول** موجودی هر اپ را ببیند، با **بسته‌ها** یا **مبلغ دلخواه** شارژ کند و تاریخچهٔ پرداخت‌ها را ببیند.
- در **نمودار مصارف** هزینهٔ روزانه در بازهٔ ۷، ۳۰ یا ۹۰ روز و هزینه به تفکیک مدل و اپ را ببیند.
- در **لاگ درخواست‌ها** هر درخواست را با توکن‌ها، هزینه و وضعیتش ببیند و بر اساس اپ، مدل، تاریخ و خطا فیلتر کند.
- **مدل‌ها و قیمت‌ها** را ببیند (دلار برای هر ۱ میلیون توکن).
- **راهنماهای اتصال** Cursor، Cline، Claude Code، n8n و OpenWebUI و API Reference را بخواند.
- **سازمان و تیم:** هر حساب یک سازمان دارد (نامش را هنگام ثبت‌نام می‌شود تعیین کرد). از صفحهٔ «تیم» اعضا را با نقش مالک، توسعه‌دهنده یا مالی دعوت کنید. منوها و صفحه‌ها بر اساس نقش نمایش داده می‌شوند. با انتخابگر بالای سایدبار بین سازمان‌ها جابه‌جا شوید.
- **سقف هزینه:** برای هر اپ سقف روزانه یا ماهانه (ماه شمسی) و برای هر کلید سقف کل، روزانه یا ماهانه بگذارید. نوار پیشرفت، مصرف دوره را نشان می‌دهد. هشدارهای ۸۰٪ و ۱۰۰٪ در زنگولهٔ اعلان‌ها و ایمیل می‌آیند.
- **بازارچهٔ ایجنت‌ها** (`/store`): ایجنت‌هایی که ادمین تعریف کرده (داخلی یا سرویس خارجی یک ناشر)، با توضیح، پارامترها و بسته‌ها. بستهٔ واحد بخرید و ایجنت را راه‌اندازی کنید.
- **ایجنت‌های من** (`/agents`): فرم تنظیمات هر ایجنت از `config_schema` همان ایجنت ساخته می‌شود (متن، عدد، انتخاب، فهرست، آدرس، کلید محرمانه و …) و برای همه زمان‌بندی (ساعت‌ها و روزها) یکسان است. خروجی‌ها در پنل دیده می‌شوند و به تلگرام، بله، ایمیل یا وب‌هوک هم فرستاده می‌شوند (هر مقصد دکمهٔ ارسال آزمایشی دارد).
- **پنل ناشر** (`/publisher`): فروش ایجنت خودتان در بازارچه. شامل درآمد خالص (سهم فروش منهای هزینهٔ مدل) و نمودار ۳۰ روزه، تسویه‌ها و پروفایل ناشر است. در ویرایشگر ایجنت (`/publisher/agents/:id`) معرفی و بسته‌ها، سازندهٔ پارامترها با پیش‌نمایش فرم مشتری (یا ویرایش JSON)، اتصال با کلید امضا، تست اتصال، اجرای آزمایشی، ارسال برای بررسی و آمار اجراها را دارید.
- در **چت** (`/chat`) با مدل‌ها گفت‌وگو کند. هزینه از کیف پول اپی که در سایدبار انتخاب شده کم می‌شود. تاریخچهٔ گفت‌وگوها فقط در همین مرورگر (`localStorage`) نگه داشته می‌شود.

پنل مدیریت (قیمت خرید، درصد سود، تأیید پرداخت‌ها، گزارش سود) در بک‌اند و با Filament ساخته شده است: `/admin`.

## اجرا

```bash
npm install
API_INTERNAL_URL=http://127.0.0.1:8000 npm run dev   # http://localhost:9000
```

در حالت توسعه، `/api` و `/v1` به بک‌اند لاراول proxy می‌شوند. در production هم هر دو مسیر روی همان دامنه به بک‌اند route می‌شوند (مثل پروژهٔ بیمه).

متغیر اختیاری `VITE_GATEWAY_URL`: اگر gateway روی دامنهٔ دیگری است، آدرس آن را اینجا بدهید تا در نمونه‌کدها نمایش داده شود.

```bash
npm run typecheck
npm run lint:check
npm run build      # خروجی در dist/spa
```

`Dockerfile` خروجی SPA را با nginx روی پورت 8080 سرو می‌کند.
